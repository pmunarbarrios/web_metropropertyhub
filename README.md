22. Chatbot Payload

Cuando el usuario envíe un mensaje:

{
  "sessionId": "unique-session-id",
  "message": "User message",
  "language": "en",
  "page": "/",
  "timestamp": "ISO_DATE",
  "source": "website-chatbot"
}


La respuesta esperada:

{
  "reply": "Assistant response",
  "sessionId": "unique-session-id",
  "language": "en",
  "lead": false
}


Si se detecta un lead:

{
  "reply": "Thank you. We received your information.",
  "sessionId": "unique-session-id",
  "language": "en",
  "lead": true,
  "leadId": "12345"
}
